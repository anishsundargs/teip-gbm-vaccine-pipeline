**TEIP** (Tumor Epitope Immunogenicity Pipeline) is a research-use computational framework for **glioblastoma (GBM) vaccine target prioritization**. The pipeline supports candidate **peptide-HLA scoring**, **OIP5-derived epitope analysis**, and computational ranking of potential GBM immunotherapy targets.

TEIP is designed for bioinformatics and engineering research involving:

- glioblastoma vaccine target prediction
- GBM peptide-HLA candidate prioritization
- tumor epitope immunogenicity scoring
- OIP5 glioblastoma antigen analysis
- cancer vaccine bioinformatics
- computational immunotherapy target discovery
- personalized immunotherapy target ranking

## Public TEIP Web App

[Open the TEIP public web app](https://teip-gbm-vaccine-pipeline.streamlit.app/)

The web app allows users to upload candidate peptide-HLA CSV files and receive ranked TEIP candidate scores.

## What TEIP does

TEIP provides a computational interface for ranking candidate tumor epitopes using peptide-HLA information and tumor-context features. It is intended for early-stage research workflows in glioblastoma vaccine design and computational immuno-oncology.

## Research-use disclaimer

TEIP is not clinically validated. It does not diagnose disease, prove vaccine efficacy, or make treatment recommendations. All candidate epitopes require experimental validation.
